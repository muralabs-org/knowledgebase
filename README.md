# MURA LABS Knowledge Base

The published pages of the knowledge base of the MURA LABS JP-series amplifier modules:
**https://docs.muralabs.org/** (while the domain is being set up: https://muralabs-org.github.io/knowledgebase/).

## A mistake on a page

The bug icon at the top of every page opens a report here with the page's address filled in;
[this link](https://github.com/muralabs-org/knowledgebase/issues/new?template=page-problem.yml)
opens an empty one. A problem with a module itself goes to
[support](https://docs.muralabs.org/support/contact/), not here.

## Downloads

The files of each firmware release, the update bundle, MuraLink and the SigmaStudio starter
project, are attached to the [releases](https://github.com/muralabs-org/knowledgebase/releases) of
this repository. The [Downloads](https://docs.muralabs.org/releases/downloads/) page of the site
lists them.

## About this repository

The pages are written and built elsewhere and published to the `gh-pages` branch, which is replaced
with every update. The `main` branch holds this file and the report form only, so a pull request
here cannot change a page; please report the mistake instead.
